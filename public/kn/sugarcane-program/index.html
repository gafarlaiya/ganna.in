Immunity Sugarcane Program

Plantation ನಿಂದ Harvest ವರೆಗೆ: ಪ್ರತಿ stage ಗೆ ಸರಿಯಾದ ಸಮಯದಲ್ಲಿ ಸರಿಯಾದ dose.

ಸಂಕ್ಷಿಪ್ತ ಉತ್ತರ

Immunity Sugarcane Program ಮೂರು products (Immunity Granules, Sugarcane Special ಮತ್ತು Gold) ಜೊತೆ Plantation ನಿಂದ 2–4 leaves ಮತ್ತು repeat spray ವರೆಗಿನ stage-wise program.

ನಾಲ್ಕು ಹಂತಗಳಲ್ಲಿ ಸಂಪೂರ್ಣ Program

1

Plantation

Immunity Granules 8–12 KG / ವೀಘಾ (20–30 KG / ಎಕರೆ) root zone ನಲ್ಲಿ.

2

ಮೊದಲ ನೀರಿನ ನಂತರ

Sugarcane Special drenching 0.5–0.7 L / ವೀಘಾ (herbicide ನ 3-4 ದಿನಗಳ ನಂತರ).

2–4 Leaves

Special + Gold foliar spray: 250 ML + 250 ML / ವೀಘಾ, 4–5 ಪಂಪ್.

Repeat

ಪ್ರತಿ 15–25 ದಿನಗಳಿಗೊಮ್ಮೆ 2–3 sprays; ಪ್ರತಿ ಮುಖ್ಯ fertilizer dose ಜೊತೆ Granules 1 bag.

ನಿಮ್ಮ ಕಬ್ಬು ಯಾವ stage ನಲ್ಲಿದೆ?

🌱 Plantation ಇನ್ನೂ ಬಾಕಿ ಇದೆ

  • Plantation ಸಮಯದಲ್ಲಿ Granules 8–12 KG / ವೀಘಾ
  • ನಂತರ early drenching 0.5–0.7 L / ವೀಘಾ
  • 2–4 leaves ನಲ್ಲಿ Special + Gold spray
  • ಪ್ರತಿ 15–25 ದಿನಗಳಿಗೊಮ್ಮೆ ಮುಂದಿನ program

✅ Plantation ಆಗಿದೆ

  • ಮೊದಲ ನೀರು ಯಾವಾಗ ಎಂದು ನೋಡಿ
  • Herbicide ಕೊಟ್ಟಿದ್ದರೆ 3-4 ದಿನಗಳ ನಂತರ drenching
  • 2–4 leaves ಯಾವಾಗ ಬರುತ್ತವೆ ಎಂದು ನೋಡಿ
  • ನಿಮ್ಮ crop ಗೆ ತಕ್ಕಂತೆ spray program ಹೊಂದಿಸಿ

ಪದೇ ಪದೇ ಕೇಳುವ ಪ್ರಶ್ನೆಗಳು

Plantation ಸಮಯದಲ್ಲಿ Granules ಎಷ್ಟು ಕೊಡಬೇಕು?

Current program ಪ್ರಕಾರ 1 ವೀಘಾಕ್ಕೆ 8–12 KG (ಅಥವಾ 1 ಎಕರೆಗೆ 20–30 KG) Immunity Granules ಅನ್ನು Plantation ಸಮಯದಲ್ಲಿ ಕೊಡಬೇಕು.

Sugarcane Special Drenching ಯಾವಾಗ ಮತ್ತು ಎಷ್ಟು ಮಾಡಬೇಕು?

ಮೊದಲ ನೀರಿನ ನಂತರ / ಕಳೆನಾಶಕ ಸಿಂಪಡಿಸಿದ 3-4 ದಿನಗಳ ನಂತರ, ಪ್ರತಿ ವೀಘಾಕ್ಕೆ 0.5–0.7 Litres (500–700 ML).

Herbicide ಕೊಟ್ಟಿದ್ದರೆ?

Herbicide ಬಳಸಿದ 3-4 ದಿನಗಳ ನಂತರ drenching program ಇಡುವುದು ಸಲಹೆ.

2–4 leaves ಹಂತದ spray ನಲ್ಲಿ ಏನು ಕೊಡಬೇಕು ಮತ್ತು ಎಷ್ಟು ಪಂಪ್ ಹೊಡೆಯಬೇಕು?

ಪ್ರತಿ ವೀಘಾಕ್ಕೆ 4-5 ಸ್ಪ್ರೇ ಪಂಪ್. ಪ್ರತಿ 15 ಲೀಟರ್ ಪಂಪ್‌ನಲ್ಲಿ 45-50 ML Immunity Sugarcane Special + 45-50 ML Immunity Gold (ಒಟ್ಟು ಪ್ರತಿ ವೀಘಾಕ್ಕೆ 250 ML + 250 ML).

Spray ಎಷ್ಟು ದಿನಗಳ ನಂತರ repeat ಮಾಡಬೇಕು?

ಸಾಮಾನ್ಯವಾಗಿ 15–25 ದಿನಗಳ interval ನಲ್ಲಿ, crop condition ಪ್ರಕಾರ ಮುಂದಿನ 2–3 sprays.

Plantation ನಂತರ Granules ಮುಂದುವರಿಸಬೇಕೇ?

Program ಪ್ರಕಾರ ಹೌದು: ನಂತರ fertilizer ನ ಪ್ರತಿ ಮುಖ್ಯ dose ಜೊತೆ Granules 1 bag ಪ್ರಕಾರ ಮುಂದುವರಿಸುವುದು ಸಲಹೆ.

*ಈ ಮಾಹಿತಿ ಸಾಮಾನ್ಯ ಮಾರ್ಗದರ್ಶನ ಮತ್ತು current program guidance. ಫಲಿತಾಂಶಗಳು ಮಣ್ಣು, variety, ನೀರು, ಹವಾಮಾನ ಮತ್ತು management ಪ್ರಕಾರ ಬದಲಾಗಬಹುದು; ಯಾವುದೇ ಫಲಿತಾಂಶ guaranteed ಅಲ್ಲ. ಹೊಲದ ಸ್ಥಿತಿಗೆ ತಕ್ಕ ಸರಿಯಾದ ಸಲಹೆಗೆ Call ಮಾಡಿ.

ನಿಮ್ಮ ಕಬ್ಬಿಗೆ ನೇರ ಸಲಹೆ ಬೇಕೇ?

ನಿಮ್ಮ ಈಗಿನ crop stage (Plantation, ಮೊದಲ ನೀರು, Herbicide, 2–4 leaves) ತಿಳಿಸಿ ಮತ್ತು program ಬಗ್ಗೆ ತಿಳಿಯಿರಿ.
