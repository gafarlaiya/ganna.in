પ્રશ્નો

Plantation વખતે Granules કેટલા આપવાના?

Current program પ્રમાણે 1 વીઘા દીઠ 8–12 KG (અથવા 1 એકર દીઠ 20–30 KG) Immunity Granules Plantation વખતે આપવાના છે.

Sugarcane Special Drenching ક્યારે અને કેટલી કરવી?

પ્રથમ પિયત પછી / ઘાસ મારવાની દવા પાયાના 3-4 દિવસ પછી, 0.5–0.7 Litres (500–700 ML) પ્રતિ વીઘા.

Herbicide આપ્યું હોય તો?

Herbicide વાપર્યા પછી પાયાના 3-4 દિવસ બાદ drenching program રાખવાની સલાહ છે.

2–4 leaves પર sprayમાં શું આપવું અને કેટલા પંપ કરવા?

પ્રતિ વીઘા 4-5 સ્પ્રે પંપ. દર 15 લિટર પંપમાં 45-50 ML Immunity Sugarcane Special + 45-50 ML Immunity Gold (કુલ 250 ML + 250 ML પ્રતિ વીઘા).

Spray કેટલા દિવસે repeat કરવો?

સામાન્ય રીતે 15–25 દિવસના intervalથી, crop condition પ્રમાણે આગળના 2–3 sprays.

1 એકર માટે કેટલી માત્રા થાય?

1 એકર = 2.5 વીઘા લેતાં: Granules 20–30 KG, Sugarcane Special drenching 1.25–1.75 L, foliar spray માટે 625 ML Special + 625 ML Gold (લગભગ 10–12.5 પંપ).

*આ માહિતી સામાન્ય માર્ગદર્શન અને current program guidance છે. પરિણામો જમીન, variety, પાણી, હવામાન અને management પ્રમાણે બદલાઈ શકે છે; કોઈ પણ પરિણામ guaranteed નથી. ખેતરની સ્થિતિ પ્રમાણે યોગ્ય સલાહ માટે Call કરો.

તમારી શેરડી માટે સીધી સલાહ જોઈએ છે?

તમારી હાલની crop stage (Plantation, પ્રથમ પિયત, Herbicide, 2–4 leaves) જણાવો અને program વિશે જાણો.
