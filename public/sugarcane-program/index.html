Immunity Sugarcane Program

Plantationથી Harvest સુધી: દરેક stage માટે યોગ્ય સમયે યોગ્ય dose.

ટૂંકો જવાબ

Immunity Sugarcane Program ત્રણ products (Immunity Granules, Sugarcane Special અને Gold) સાથે Plantationથી 2–4 leaves અને repeat spray સુધીનો stage-wise program છે.

ચાર સ્ટેપમાં આખો Program

1

Plantation

Immunity Granules 8–12 KG / વીઘા (20–30 KG / એકર) root zoneમાં.

2

પ્રથમ પિયત પછી

Sugarcane Special drenching 0.5–0.7 L / વીઘા (herbicide પછી 3-4 દિવસે).

3

2–4 Leaves

Special + Gold foliar spray: 250 ML + 250 ML / વીઘા, 4–5 પંપ.

4

Repeat

દર 15–25 દિવસે 2–3 sprays; દરેક મુખ્ય fertilizer dose સાથે Granules 1 bag.

તમારી શેરડી કયા stageમાં છે?

🌱 Plantation હજુ બાકી છે

  • Plantation વખતે Granules 8–12 KG / વીઘા
  • પછી early drenching 0.5–0.7 L / વીઘા
  • 2–4 leaves પર Special + Gold spray
  • દર 15–25 દિવસે આગળનું program

✅ Plantation થઈ ગયું છે

  • પ્રથમ પિયત ક્યારે છે તે જુઓ
  • Herbicide આપ્યું હોય તો 3-4 દિવસ પછી drenching
  • 2–4 leaves ક્યારે પહોંચે છે તે જુઓ
  • તમારા crop પ્રમાણે spray program ગોઠવો
📋 પૂરું ડોઝ શેડ્યૂલ અને Calculator

વારંવાર પૂછાતા પ્રશ્નો

Plantation વખતે Granules કેટલા આપવાના?

Current program પ્રમાણે 1 વીઘા દીઠ 8–12 KG (અથવા 1 એકર દીઠ 20–30 KG) Immunity Granules Plantation વખતે આપવાના છે.

Sugarcane Special Drenching ક્યારે અને કેટલી કરવી?

પ્રથમ પિયત પછી / ઘાસ મારવાની દવા પાયાના 3-4 દિવસ પછી, 0.5–0.7 Litres (500–700 ML) પ્રતિ વીઘા.

Herbicide આપ્યું હોય તો?

Herbicide વાપર્યા પછી પાયાના 3-4 દિવસ બાદ drenching program રાખવાની સલાહ છે.

2–4 leaves પર sprayમાં શું આપવું અને કેટલા પંપ કરવા?

પ્રતિ વીઘા 4-5 સ્પ્રે પંપ. દર 15 લિટર પંપમાં 45-50 ML Immunity Sugarcane Special + 45-50 ML Immunity Gold (કુલ 250 ML + 250 ML પ્રતિ વીઘા).

Spray કેટલા દિવસે repeat કરવો?

સામાન્ય રીતે 15–25 દિવસના intervalથી, crop condition પ્રમાણે આગળના 2–3 sprays.

Plantation પછી Granules ચાલુ રાખવા?

Program પ્રમાણે હા: ત્યારબાદ fertilizerના દરેક મુખ્ય dose સાથે Granules 1 bag પ્રમાણે ચાલુ રાખવાની સલાહ છે.

*આ માહિતી સામાન્ય માર્ગદર્શન અને current program guidance છે. પરિણામો જમીન, variety, પાણી, હવામાન અને management પ્રમાણે બદલાઈ શકે છે; કોઈ પણ પરિણામ guaranteed નથી. ખેતરની સ્થિતિ પ્રમાણે યોગ્ય સલાહ માટે Call કરો.

તમારી શેરડી માટે સીધી સલાહ જોઈએ છે?

તમારી હાલની crop stage (Plantation, પ્રથમ પિયત, Herbicide, 2–4 leaves) જણાવો અને program વિશે જાણો.
