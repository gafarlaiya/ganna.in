Immunity Sugarcane Program

Plantation ਤੋਂ Harvest ਤੱਕ: ਹਰ stage ਲਈ ਸਹੀ ਵੇਲੇ ਸਹੀ dose.

ਛੋਟਾ ਜਵਾਬ

Immunity Sugarcane Program ਤਿੰਨ products (Immunity Granules, Sugarcane Special ਅਤੇ Gold) ਨਾਲ Plantation ਤੋਂ 2–4 leaves ਅਤੇ repeat spray ਤੱਕ ਦਾ stage-wise program ਹੈ।

ਚਾਰ ਸਟੈਪਾਂ ਵਿੱਚ ਪੂਰਾ Program

1

Plantation

Immunity Granules 8–12 KG / ਵੀਘਾ (20–30 KG / ਏਕੜ) root zone ਵਿੱਚ।

2

ਪਹਿਲੇ ਪਾਣੀ ਤੋਂ ਬਾਅਦ

Sugarcane Special drenching 0.5–0.7 L / ਵੀਘਾ (herbicide ਤੋਂ 3-4 ਦਿਨ ਬਾਅਦ)।

3

2–4 Leaves

Special + Gold foliar spray: 250 ML + 250 ML / ਵੀਘਾ, 4–5 ਪੰਪ।

4

Repeat

ਹਰ 15–25 ਦਿਨਾਂ ਬਾਅਦ 2–3 sprays; ਹਰ ਮੁੱਖ fertilizer dose ਨਾਲ Granules 1 bag.

ਤੁਹਾਡਾ ਗੰਨਾ ਕਿਹੜੀ stage ਵਿੱਚ ਹੈ?

🌱 Plantation ਹਾਲੇ ਬਾਕੀ ਹੈ

  • Plantation ਵੇਲੇ Granules 8–12 KG / ਵੀਘਾ
  • ਫਿਰ early drenching 0.5–0.7 L / ਵੀਘਾ
  • 2–4 leaves ਤੇ Special + Gold spray
  • ਹਰ 15–25 ਦਿਨਾਂ ਬਾਅਦ ਅਗਲਾ program

✅ Plantation ਹੋ ਚੁੱਕੀ ਹੈ

  • ਪਹਿਲਾ ਪਾਣੀ ਕਦੋਂ ਹੈ, ਇਹ ਦੇਖੋ
  • Herbicide ਪਾਈ ਹੋਵੇ ਤਾਂ 3-4 ਦਿਨ ਬਾਅਦ drenching
  • 2–4 leaves ਕਦੋਂ ਆਉਂਦੇ ਹਨ, ਇਹ ਦੇਖੋ
  • ਆਪਣੀ crop ਮੁਤਾਬਕ spray program ਤੈਅ ਕਰੋ
📋 ਪੂਰਾ ਡੋਜ਼ ਸ਼ਡਿਊਲ ਅਤੇ Calculator

ਅਕਸਰ ਪੁੱਛੇ ਜਾਂਦੇ ਸਵਾਲ

Plantation ਵੇਲੇ Granules ਕਿੰਨੇ ਪਾਉਣੇ ਹਨ?

Current program ਮੁਤਾਬਕ 1 ਵੀਘੇ ਵਿੱਚ 8–12 KG (ਜਾਂ 1 ਏਕੜ ਵਿੱਚ 20–30 KG) Immunity Granules Plantation ਵੇਲੇ ਪਾਉਣੇ ਹਨ।

Sugarcane Special Drenching ਕਦੋਂ ਅਤੇ ਕਿੰਨੀ ਕਰਨੀ ਹੈ?

ਪਹਿਲੇ ਪਾਣੀ ਤੋਂ ਬਾਅਦ / ਨਦੀਨਨਾਸ਼ਕ ਦਵਾਈ ਤੋਂ 3-4 ਦਿਨ ਬਾਅਦ, 0.5–0.7 Litres (500–700 ML) ਪ੍ਰਤੀ ਵੀਘਾ।

Herbicide ਪਾਈ ਹੋਵੇ ਤਾਂ?

Herbicide ਵਰਤਣ ਤੋਂ 3-4 ਦਿਨ ਬਾਅਦ drenching program ਰੱਖਣ ਦੀ ਸਲਾਹ ਹੈ।

2–4 leaves ਤੇ spray ਵਿੱਚ ਕੀ ਪਾਉਣਾ ਹੈ ਅਤੇ ਕਿੰਨੇ ਪੰਪ ਮਾਰਨੇ ਹਨ?

ਪ੍ਰਤੀ ਵੀਘਾ 4-5 ਸਪਰੇਅ ਪੰਪ। ਹਰ 15 ਲੀਟਰ ਪੰਪ ਵਿੱਚ 45-50 ML Immunity Sugarcane Special + 45-50 ML Immunity Gold (ਕੁੱਲ 250 ML + 250 ML ਪ੍ਰਤੀ ਵੀਘਾ)।

Spray ਕਿੰਨੇ ਦਿਨਾਂ ਬਾਅਦ repeat ਕਰਨੀ ਹੈ?

ਆਮ ਤੌਰ ਤੇ 15–25 ਦਿਨਾਂ ਦੇ interval ਤੇ, crop condition ਮੁਤਾਬਕ ਅਗਲੀਆਂ 2–3 sprays.

ਕੀ Plantation ਤੋਂ ਬਾਅਦ Granules ਜਾਰੀ ਰੱਖੀਏ?

Program ਮੁਤਾਬਕ ਹਾਂ: ਉਸ ਤੋਂ ਬਾਅਦ fertilizer ਦੀ ਹਰ ਮੁੱਖ dose ਨਾਲ Granules 1 bag ਦੇ ਹਿਸਾਬ ਨਾਲ ਜਾਰੀ ਰੱਖਣ ਦੀ ਸਲਾਹ ਹੈ।

*ਇਹ ਜਾਣਕਾਰੀ ਆਮ ਮਾਰਗਦਰਸ਼ਨ ਅਤੇ current program guidance ਹੈ। ਨਤੀਜੇ ਜ਼ਮੀਨ, variety, ਪਾਣੀ, ਮੌਸਮ ਅਤੇ management ਮੁਤਾਬਕ ਬਦਲ ਸਕਦੇ ਹਨ; ਕੋਈ ਵੀ ਨਤੀਜਾ guaranteed ਨਹੀਂ ਹੈ। ਖੇਤ ਦੀ ਹਾਲਤ ਮੁਤਾਬਕ ਸਹੀ ਸਲਾਹ ਲਈ Call ਕਰੋ।

ਆਪਣੇ ਗੰਨੇ ਲਈ ਸਿੱਧੀ ਸਲਾਹ ਚਾਹੀਦੀ ਹੈ?

ਆਪਣੀ ਮੌਜੂਦਾ crop stage (Plantation, ਪਹਿਲਾ ਪਾਣੀ, Herbicide, 2–4 leaves) ਦੱਸੋ ਅਤੇ program ਬਾਰੇ ਜਾਣੋ।
